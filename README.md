# برنامهٔ بومی جامعه‌الهدی

این مخزن اپلیکیشن اندرویدی مستقل با Kotlin و Jetpack Compose است. رابط اصلی با اجزای بومی اندروید ساخته شده و وب‌سایت داخل WebView قرار نمی‌گیرد.

- وب‌سایت رسمی: https://jametulhoda.vercel.app/
- فید برنامه: `https://jametulhoda.vercel.app/api/mobile-feed`
- شناسهٔ بسته فعلی: `com.aistudio.jametulhoda.app`
- پشتیبانی: Android 7.0 / API 24 به بالا

## قابلیت‌های نسخهٔ فعلی

- رابط فارسی راست‌به‌چپ و نوار ناوبری بومی
- بخش خانه، اخبار، پژوهش، کتابخانه و بیشتر
- جستجو، صفحهٔ جزئیات مطلب و اشتراک‌گذاری
- کش محدود آخرین فید موفق برای مشاهدهٔ متن‌های قبلی بدون اینترنت
- ورود، ثبت‌نام، مشاهده/ویرایش پروفایل، تغییر رمز و خروج از طریق Bearer API؛ توکن فقط به‌شکل رمز‌شده در فضای بدون پشتیبان Android Keystore نگه‌داری می‌شود
- حالت روشنِ پیش‌فرض با انتخاب ماندگار حالت تاریک در بخش «بیشتر»
- نمایش تصویرهای https با بارگذاری تنبل و کش کوتاه حافظه
- دریافت فقط محتوای عمومی منتشرشده از API سایت؛ بدون دسترسی به اطلاعات خصوصی حساب‌ها
- عدم استفاده از اتصال شبکه‌های اجتماعی در برنامه
- حذف SDKهای Firebase استفاده‌نشده و فعال‌سازی کوچک‌سازی کد و منابع برای نسخهٔ release

## ساخت APK آزمایشی

گردش‌کار **Build Android APK** در GitHub Actions به‌صورت خودکار اجرا می‌شود.

1. مخزن را باز کنید و به زبانهٔ **Actions** بروید.
2. آخرین اجرای سبز **Build Android APK** را باز کنید.
3. از بخش **Artifacts** فایل `jametulhoda-debug-apk` را دریافت کنید.
4. ZIP را استخراج و `app-debug.apk` را نصب کنید.

APK آزمایشی با کلید debug امضا می‌شود و برای انتشار مستقیم در Google Play مناسب نیست. انتشار نیازمند کلید بارگذاری امن، فایل AAB امضاشده، اطلاعات حریم خصوصی، تکمیل بخش Data safety و بررسی روی دستگاه واقعی است. هدف حجم حدود ۱۰ مگابایت است، اما باید اندازهٔ فایل نهایی اندازه‌گیری شود؛ حجم تضمین‌شده نیست.

## قرارداد داده

فید عمومی فقط از API وب‌سایت رسمی دریافت می‌شود و شامل محتوای منتشرشده‌ای است که بک‌اند مجاز به نمایش آن است. مسیر فعلی `GET /api/mobile-feed` است. کلاینت حساب کاربری به قرارداد `/api/mobile-auth` وابسته است؛ تا زمانی که PR بک‌اند این مسیر در مخزن وب ادغام و در Production منتشر نشده باشد، ورود و ثبت‌نام از سرور زنده قابل استفاده نیست. صفحه‌بندی سراسری، جست‌وجوی سمت سرور، پخش‌کنندهٔ مستقل رسانه و مسیر‌یابی کامل بومی همچنان نیازمند تکمیل و آزمون جداگانه‌اند؛ این موارد را تکمیل‌شده تلقی نکنید.

## حریم خصوصی و امنیت

- مجوزهای اندروید به اینترنت و وضعیت اتصال شبکه محدود است.
- اطلاعات خصوصی حساب در فید عمومی ارسال نمی‌شود.
- پیوند منبع فعلی در مرورگر خارجی باز می‌شود؛ ناوبری بومی همهٔ مسیرهای سایت هنوز تکمیل نشده است.
- درخواست شبکه فقط از HTTPS استفاده می‌کند.
