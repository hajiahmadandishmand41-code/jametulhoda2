# اپلیکیشن جامعة الهدی

پروژهٔ اندرویدی Kotlin و Jetpack Compose برای دسترسی به وب‌سایت جامعة الهدی از داخل Android WebView.

- وب‌سایت: https://jametulhoda.vercel.app/
- شاخهٔ اصلی: `main`
- شناسهٔ فعلی برنامه: `com.aistudio.jametulhoda.app`
- نسخهٔ فعلی: `1.0`

## ساخت APK با گوشی یا مرورگر

ساخت با GitHub Actions انجام می‌شود و نصب Android Studio روی تلفن لازم نیست.

1. تغییرات را در شاخهٔ `main` ثبت کنید، یا در برگهٔ Actions گردش‌کار **Build Android APK** را با **Run workflow** اجرا کنید.
2. اجرای گردش‌کار را باز کنید و منتظر پایان موفق build و آزمون واحد بمانید.
3. در اجرای موفق، از بخش **Artifacts** فایل `jametulhoda-debug-apk` را دریافت کنید.
4. ZIP دانلودشده را استخراج و فایل `app-debug.apk` را روی دستگاه اندرویدی نصب کنید.

این فایل، APK آزمایشی با امضای debug است. برای انتشار در Google Play باید امضای release با کلید ثابت و محرمانه، شناسهٔ بستهٔ نهایی، سیاست حریم خصوصی و آزمون دستگاه واقعی آماده شود. کلید خصوصی یا رمز امضا را در مخزن عمومی ثبت نکنید.

## ساخت محلی

این مخزن Gradle Wrapper استاندارد ندارد. گردش‌کار GitHub نسخهٔ Gradle سازگار با Android Gradle Plugin پروژه را نصب می‌کند و وظایف `testDebugUnitTest` و `assembleDebug` را اجرا می‌کند.

## یادداشت امنیتی

وب‌سایت در WebView بارگذاری می‌شود. ترافیک HTTP غیراِمن و محتوای مختلط غیرفعال‌اند و دسترسی مستقیم WebView به فایل محلی بسته است. ورودها، لینک‌های خارجی، بارگذاری/دانلود فایل و حالت آفلاین باید همچنان در دستگاه واقعی آزمون شوند.
